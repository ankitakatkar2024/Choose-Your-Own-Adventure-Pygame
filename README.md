# 🎮 Choose Your Own Adventure

A graphical 2D adventure game developed using Python and Pygame. Players explore different environments, make decisions, and experience different story outcomes.

## Features

- Graphical game interface
- Illustrated scene backgrounds
- Interactive buttons and choices
- Player name input
- Animated character movement
- Water ripple animation
- Bridge crossing animation
- Typing dialogue effect
- Background ambience and sound effects
- Win and Game Over screens
- Restart functionality

## Technologies Used

- Python 3
- Pygame
- WAV audio assets

## Installation and Setup

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd Choose-Your-Own-Adventure-Pygame
```

3. Install dependencies:

```bash
python -m pip install -r requirements.txt
```

4. Run the game:

```bash
python main.py
```

## Gameplay

1. Enter your player name.
2. Choose left or right at the starting road.
3. Explore the river or cross the bridge.
4. Interact with the stranger.
5. Reach the winning destination or experience Game Over.
